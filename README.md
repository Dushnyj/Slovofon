## Возможности

- **Поиск по нескольким источникам** — находите книги по названию, автору или чтецу и выбирайте озвучку.
- **Прослушивание без интернета** — скачивайте книги целиком или отдельные главы.
- **Продолжение с сохранённого места** — возвращайтесь к начатой книге без поиска нужного момента.
- **Своя библиотека** — избранное, список «Позже», закладки и история.
- **Удобный плеер** — настройка скорости, перемотка и таймер сна.
- **Оформление под себя** — светлая и тёмная темы, акцентный цвет и размер текста.

> [!NOTE]
> Регистрация не нужна. Библиотека и прогресс хранятся на устройстве, без синхронизации между устройствами.
