# Slovofon v0.0.6

Патч-релиз с исправлением залипшего sleep timer, из-за которого книга не запускалась после истечения таймера сна.

## Главное
- Версия приложения поднята до `0.0.6+6`.
- Sleep timer больше не блокирует воспроизведение после истечения: ранее по окончании таймера его значение `0` сохранялось в базу, и при следующем запуске приложения книга мгновенно ставилась на паузу через секунду после нажатия Play. Теперь истёкший таймер корректно сбрасывается.
- Уже сохранённое «залипшее» значение у существующих пользователей тоже исправляется автоматически после обновления — вручную включать и выключать таймер больше не нужно.

## Важно
- Android APK подписан тем же upload key, что и предыдущие релизы.
- Windows installer/MSI пока без code signing certificate: Windows может показать предупреждение `Unknown Publisher`.
- Android sideload может показывать предупреждение Google Play Protect для неизвестного разработчика; это не ошибка подписи APK.
