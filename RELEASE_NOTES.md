# Slovofon v0.0.4

Патч-релиз для проверки автообновления после исправления сообщений о сетевых ошибках.

## Главное
- Версия приложения поднята до `0.0.4+4`.
- При отсутствии интернета ручная проверка обновлений и скачивание обновления показывают понятное сообщение с кнопкой `Повторить`.
- Технические ошибки вроде `SocketException`, DNS/host lookup и HTTP details больше не выводятся пользователю в update-flow.
- Startup-проверка обновлений по-прежнему не шумит при проблемах сети.

## Важно
- Android APK подписан тем же upload key, что и предыдущие релизы.
- Windows installer/MSI пока без code signing certificate: Windows может показать предупреждение `Unknown Publisher`.
- Android sideload может показывать предупреждение Google Play Protect для неизвестного разработчика; это не ошибка подписи APK.
