# Slovofon v0.0.7

Обновление интерфейса Windows, отдельная компоновка Android TV, улучшения Android
и исправления плеера, офлайн-загрузок и обновлений. Версия приложения: **0.0.7+7**.

## Главное

- **Windows:** адаптивные главная, поиск, библиотека, загрузки, настройки и карточка
  книги; разумный минимальный размер окна, постоянный нижний плеер, управление
  громкостью и горячие клавиши без перехвата ввода текста.
- **Android TV:** определение телевизора средствами Android, навигация пультом,
  крупные действия и карточки, заметный фокус, безопасные поля экрана и общий плеер.
- **Android:** действия карточек и диалоги адаптированы к крупному тексту,
  повороту экрана и клавиатуре; сенсорные цели управления увеличены.
- **Доступность:** размер текста 75–200%, предпросмотр и сброс до 100%; сохранён
  системный масштаб. Улучшены контраст, светлая/тёмная/AMOLED темы и reduced motion.
- **Плеер и источники:** исправлены восстановление позиции, гонки выбора книги,
  таймер сна и обработка ошибок. Источник показан названием своим цветом;
  в других озвучках автор не подменяет чтеца. Исправлены стрелки перемотки ±15 секунд.
- **Офлайн:** исправлены гонки паузы, возобновления и сохранения загрузок;
  локальное воспроизведение не блокируется сетевыми проверками источника.
- **Обновления напрямую с GitHub Releases:** обязательная проверка SHA-256,
  описание выпуска и действия «Обновить», «Позже», «Пропустить версию».
  Пропуск сохраняется между запусками; ручная проверка в настройках его обходит.
- **Установщики Windows:** переработаны Setup и MSI, выбор папки и ярлыков,
  удаление через настройки Windows, сохранение пользовательских данных по умолчанию,
  защита от понижения версии и смешивания типов установки.

Полный список изменений: [CHANGELOG.md](https://github.com/Dushnyj/Slovofon/blob/v0.0.7/CHANGELOG.md).

## Переход с v0.0.6

Версия `0.0.6` ещё использует прежний серверный канал обновлений и не проверяет
GitHub Releases. Для перехода на `0.0.7` скачайте подходящий файл из Assets этого
выпуска и обновите приложение вручную, сохраняя прежний формат установки.
Публикация этого релиза сама по себе не обновляет старый серверный канал.
Начиная с `0.0.7`, приложение проверяет следующие стабильные выпуски напрямую
в GitHub Releases.

## Какой файл скачать

| Устройство / назначение | Файл в Assets |
| --- | --- |
| Android-телефон, планшет или Android TV — универсальный вариант | `Slovofon-v0.0.7-android-universal-release.apk` |
| Android ARM64 | `Slovofon-v0.0.7-android-arm64-v8a-release.apk` |
| Android ARMv7 | `Slovofon-v0.0.7-android-armeabi-v7a-release.apk` |
| Android x86_64 | `Slovofon-v0.0.7-android-x86_64-release.apk` |
| Android App Bundle, не для прямой установки | `Slovofon-v0.0.7-android-release.aab` |
| Windows x64 — мастер установки Setup | `Slovofon-v0.0.7-windows-x64-setup.exe` |
| Windows x64 — Windows Installer MSI | `Slovofon-v0.0.7-windows-x64-msi.msi` |
| Windows x64 — без установщика | `Slovofon-v0.0.7-windows-x64-portable.zip` |

Все восемь файлов перечислены в `SHA256SUMS.txt`. Для установленной Windows-копии
выбирайте прежний формат: Setup поверх Setup, MSI поверх MSI. Перед ручной заменой
portable закройте приложение и распакуйте **весь ZIP**, а не только `Slovofon.exe`.

## Подпись и установка

Android-сборки используют существующий release/upload key; конфигурация подписи
и application ID не менялись. APK устанавливается с подтверждением в системном
установщике Android.

> [!CAUTION]
> **Windows-файлы пока без цифровой подписи.** SmartScreen может показать
> «Система Windows защитила ваш компьютер» и «Неизвестный издатель».
> Скачайте файл из Assets этого релиза и сверьте SHA-256 с `SHA256SUMS.txt`.
> Если вы доверяете этому выпуску, нажмите «Подробнее» → «Выполнить в любом случае».
> Отключать SmartScreen или антивирус не нужно.

Автообновление не устанавливает программу без согласия: Setup/MSI открывают мастер,
APK — системный установщик. Portable ZIP скачивается, проверяется и открывается
в папке для ручной распаковки.
