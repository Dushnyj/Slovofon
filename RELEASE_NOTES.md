# Slovofon v0.0.3

Патч-релиз для проверки автообновления после исправления внутренней версии приложения.

## Главное
- Версия приложения поднята до `0.0.3+3`.
- Исправлен рассинхрон: установленное приложение больше не должно показывать старую внутреннюю версию `0.0.1` после обновления.
- Окно обновления стало проще: показывает версию, размер файла, прогресс скачивания и скорость.
- Android updater теперь проверяет разрешение на установку APK до скачивания файла.
- Release workflow теперь проверяет совпадение `VERSION`, `pubspec.yaml` и `AppVersion` до сборки.

## Важно
- Android APK подписан тем же upload key, что и предыдущие релизы.
- Windows installer/MSI пока без code signing certificate: Windows может показать предупреждение `Unknown Publisher`.
- Android sideload может показывать предупреждение Google Play Protect для неизвестного разработчика; это не ошибка подписи APK.
