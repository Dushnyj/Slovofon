# Slovofon v0.1.0

Более отзывчивый интерфейс, полноценные переводы и исправления для Windows, Android и Android TV.

## Что нового

- **Производительность:** каталоги создают карточки по мере прокрутки, скрытые экраны не обновляются на каждом тике плеера. Поиск показывает результаты источников постепенно, отменяет устаревшие запросы и разбирает HTML вне потока интерфейса. Уменьшено число обновлений и записей данных при загрузке книг и регулировке громкости.
- **Языки:** полноценные переводы интерфейса на казахский, белорусский и украинский, включая формы чисел, длительность и системные команды Android. В выборе языка — SVG-флаги единого формата.
- **Анимации:** полные, сниженные и выключенные режимы действительно меняют поведение интерфейса; учитываются системные настройки ограничения движения.
- **Темы:** единый акцент для кнопок, выбранных пунктов, вкладок, прогресса, переключателей, ссылок и фокуса с контрастным текстом.

## Что исправлено

- **Windows:** повторный запуск выводит уже открытое окно вместо второго экземпляра. Исправлены обновления дерева доступности; обычное закрытие дожидается сохранения данных и освобождения плеера и базы.
- **Android TV:** интерфейс занимает весь экран без внешней рамки. Фокус остаётся на кнопке перемотки при повторных нажатиях. Исправлены обрезание выделения, скруглённая заливка пунктов и компоновка настроек. Эмблема баннера подготовлена из оригинала для пяти плотностей экрана.
- **Android:** окна настроек размещаются над мини-плеером и навигацией, учитывают клавиатуру и увеличенный текст; кнопки остаются доступными.
