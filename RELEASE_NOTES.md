# Slovofon v0.0.5

Патч-релиз для проверки автопоказа обновлений при старте приложения и поведения Android media session при закрытии приложения.

## Главное
- Версия приложения поднята до `0.0.5+5`.
- Проверка обновлений при старте снова должна показывать доступную новую версию без перехода в настройки.
- Кнопка `Пропустить` скрывает обновление только до закрытия приложения. При следующем запуске та же новая версия будет предложена снова.
- Если приложение смахнуть из списка последних, играющая книга продолжит воспроизводиться.
- Если книга уже остановлена и приложение смахнули, Android media session и плеер в шторке очищаются.

## Важно
- Android APK подписан тем же upload key, что и предыдущие релизы.
- Windows installer/MSI пока без code signing certificate: Windows может показать предупреждение `Unknown Publisher`.
- Android sideload может показывать предупреждение Google Play Protect для неизвестного разработчика; это не ошибка подписи APK.
