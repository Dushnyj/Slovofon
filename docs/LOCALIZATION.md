# Локализация интерфейса

Приложение содержит полные каталоги интерфейсных сообщений для `ru`, `en`,
`kk`, `be` и `uk`. Выбор языка применяется одинаково в Windows, Android,
Android TV и планшетной компоновке. Названия языков в меню пишутся на самих
языках: Русский, English, Қазақша, Беларуская, Українська.

## Источники сообщений и генерация

- `assets/l10n/{ru,en,kk,be,uk}.json` — редактируемые UTF-8 каталоги.
- `lib/app/localization/app_strings.dart` — типизированные getters и методы,
  форматирование аргументов, целочисленные формы количества и единицы измерения.
- `lib/app/localization/app_catalogs.g.dart` — сгенерированные `const`-карты.
  Приложение читает их синхронно, без сети и без загрузки JSON при запуске.
- `tools/generate_localizations.dart` — генератор на стандартной библиотеке Dart.

Из корня репозитория:

```powershell
dart run tools/generate_localizations.dart
dart run tools/generate_localizations.dart --check
flutter test test/app/localization
```

Генератор проверяет одинаковые наборы ключей, непустые строки и одинаковые
именованные параметры во всех пяти языках. `--check` дополнительно проверяет,
что сгенерированный файл соответствует исходным каталогам, ничего не записывая.
JSON не нужно регистрировать в `pubspec.yaml`: runtime использует Dart-карты.

При добавлении сообщения нужно одновременно добавить его во **все пять**
каталогов и добавить типизированный метод в `AppStrings`. Для поддерживаемого
языка нет подстановки отдельного английского сообщения: пропущенный ключ —
ошибка разработки. Только неподдерживаемый код языка целиком использует английский.
Региональные коды используют каталог соответствующего языка, например `uk_UA`.

## Числа, падежи и параметры

Параметры имеют вид `{count}`, `{sourceName}`, `{version}`. Значения вставляются
однократно и как простой текст: фигурные скобки, `$`, теги и знаки в названиях
книг или источников не интерпретируются повторно.

Для целых количеств RU/BE/UK используются категории one/few/many с отдельным
случаем 11–14; English и Қазақша используют one для 1. В казахском существительное
после количества остаётся в единственном числе. Формы хранятся полными фразами,
чтобы «показать ещё», количество объектов и «из N глав» могли иметь разные падежи.
Правила сверены с [Unicode CLDR, Language Plural Rules](https://www.unicode.org/cldr/charts/48/supplemental/language_plural_rules.html).

Номера глав и вкладок — числовые позиции, а не автоматически склоняемые
порядковые числительные. Это исключает неверные суффиксы для 3, 6, 21 и т. п.
Казахская позиция имеет формат `Тарау 3 / 21`, номер — `3-тарау`.

Короткие длительности (`сағ/мин`, `гадз/хв`, `год/хв`), скорости загрузки,
единицы файлов и подписи таймера локализуются. Десятичный разделитель размера
файла определяется `intl` по языку интерфейса.

## Границы локализации

- Названия книги, авторы, чтецы, описание и названия глав из источника — контент,
  а не интерфейс. Приложение не переводит и не меняет его автоматически.
- Сохранённые канонические подписи длительности распознаются только в известном
  формате и форматируются при показе; база и скачанные файлы не перезаписываются.
- `Словофон` используется только для русского интерфейса, остальные языки —
  `Slovofon`. Имена поставщиков контента и технические термины вроде ZIP/AMOLED
  сохраняются, где это необходимо.
- Android `values-kk`, `values-be`, `values-uk` содержат локальные имя приложения,
  канал и команды системного медиаплеера. Эти нативные ресурсы выбирает Android
  по системной локали; Flutter-меню выбирает локаль приложения.

## Регрессионная защита

`catalog_completeness_test.dart` проверяет каталоги, параметры, отсутствие
английского fallback у новых переводов, все 307 существовавших публичных строк
AppStrings, региональные локали, подстановку аргументов и локальные единицы.
`fixtures/ru_en_v009.json` — снимок всех этих RU/EN результатов из реализации
версии 0.0.9 до миграции, а не ожидаемые значения из нового каталога.
`app_strings_test.dart` сохраняет прежние RU/EN падежные и смысловые проверки.
