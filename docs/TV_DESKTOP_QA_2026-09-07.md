## Нативная проверка Android TV

Один изолированный AVD `Slovofon_TV_Redesign_Debug_API36`, Android TV API 36,
2 GB RAM, **1920×1080 при 320 dpi**. Другой эмулятор одновременно не запускался.
В приложении использовались реальные «Белые ночи», источник Изибук (`izib/art4331`),
тёмная тема и пользовательский фиолетовый акцент `#7C3AED`.

Нативно наблюдались карточка и обложка, воспроизведение/изменение прогресса,
полный плеер, настройки, выбор пользовательского цвета и экранная клавиатура.
Подтверждена цепочка **поиск → Down в поле/IME → Back закрывает IME → Up
возвращает фокус в верхнее меню**. Локальные снимки в `native-tv/`:

- `20260907-022333-667-search-nav.png`;
- `20260907-022354-199-search-down-focus.png`;
- `20260907-022408-567-search-ime-hidden.png`;
- `20260907-022423-249-search-up-fixed.png`.

В дополнительном проходе подтверждено сохранение закладки без заметки:
открытие диалога → Back скрывает IME → Down выделяет кнопку сохранения →
Select добавляет запись на 07:15. Снимки `023317-255-bookmark-new-final`,
`023340-124-bookmark-ime-hidden-final`, `023358-799-bookmark-save-focus-final`,
`023420-507-bookmark-saved-verified` от 2026-09-07 показывают состояния.
Начальное открытие выполнялось ADB tap, финальные переходы — ADB keyevent;
это не проверка физического Bluetooth/IR-пульта. Ввод и редактирование русской
заметки в этом проходе не проверялись.

**Границы:**
Попытка принудительно получить нативный 4K-режим не сработала; выполнены
`wm size reset` и `wm density reset`. Поэтому 4K здесь покрыт только fixture
рендерами/тестами, а не эмулятором или физическим телевизором.

## Нативная проверка Windows: частичная, с открытым дефектом

Просмотрены Главная, настройки и библиотека, изменение ширины окна с 1280 до
1920 при разворачивании. Затем процесс завершился при работе с UI Automation.
Локальный разбор дампа с совпадающими private PDB подтвердил разыменование
нулевого дочернего узла в `flutter::FlutterPlatformNodeDelegate::ChildAtIndex`
в `flutter_windows.dll` Flutter 3.44.0; стек проходит через accessibility/UIA.

Это **открытый дефект на границе Flutter SDK/accessibility, не PASS нативного
Windows QA**. Причина рассогласования дочернего узла/счётчика пока не установлена;
дамп не доказывает связь с DPI, плеером или планшетной компоновкой. SDK не патчился,
accessibility не отключалась. Отдельное событие FFI при закрытии установленной
версии также описано отдельно и не объединяется с UIA-сбоем Debug-версии.
Подробности остаются в локальном `NATIVE_WINDOWS_CRASH_NOTES.md` рядом с артефактами.

После перезапуска Debug отдельно проверено сужение за правую и нижнюю рамки:
окно остановилось на **900×600 DIP клиентской области** (снимок вместе с рамкой
902×632 при 100% DPI), а не уменьшилось до запрошенных 600×350. Боковая панель
перешла в компактную навигацию, контент — в одну колонку. Настройки при этом
доступны с прокруткой; размер текста переключён на 200%, проверен визуально и
возвращён к 100%. Воспроизведение поставлено на паузу. Этот успешный сценарий
геометрии не отменяет описанный выше accessibility-сбой.
