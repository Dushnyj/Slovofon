# Быстрый старт

**Найдите книгу, выберите чтеца и продолжайте слушать с сохранённого места.**

[Главная страница](../README.md) · [Вся документация](README.md) · [Скачать](https://github.com/Dushnyj/Slovofon/releases) · [Помощь](../SUPPORT.md)

Это руководство для пользователей Android, Android TV и Windows.
Для запуска проекта из исходников перейдите к [инструкции по сборке](BUILD_RELEASE.md).

## Установка

Откройте [GitHub Releases проекта](https://github.com/Dushnyj/Slovofon/releases),
выберите опубликованный выпуск и раскройте **Assets**. Описание выпуска определяет,
какие сборки доступны и какие ограничения у них есть.

| Устройство | Какой файл выбрать |
| --- | --- |
| Android-телефон или планшет | `Slovofon-v<версия>-android-universal-release.apk` |
| Android TV | Тот же universal APK, если выпуск содержит TV-адаптацию. Отдельное приложение не требуется. |
| Windows x64 | `Slovofon-v<версия>-windows-x64-setup.exe` |
| Windows без установки | `Slovofon-v<версия>-windows-x64-portable.zip`, **если приложен к выпуску**. |

`<версия>` здесь — шаблон, а не ссылка на готовый файл. Номер в исходниках может
быть новее последнего опубликованного выпуска. **Source code (zip/tar.gz)** —
архив исходников, он не заменяет APK или установщик.

### Android-телефон и планшет

1. Скачайте universal APK из выбранного выпуска.
2. Откройте файл. Если Android попросит разрешить установку из этого источника,
   предоставьте разрешение используемому браузеру или файловому менеджеру.
3. Завершите установку и откройте **Словофон**. В нерусской локализации название — **Slovofon**.
4. При запросе разрешения на уведомления разрешите их, если хотите видеть
   системное управление воспроизведением.

Для обновления используйте совместимую сборку поверх установленной. Если Android
сообщает о конфликте подписи, не удаляйте рабочую установку ради обхода ошибки:
Debug APK и Release APK могут иметь разные подписи. Уточните тип сборки в описании
выпуска или в [обращении в поддержку](../SUPPORT.md).

### Android TV

1. Выберите выпуск с TV-адаптацией и передайте его universal APK на телевизор
   доступным вам способом, например через USB и файловый менеджер.
2. Откройте APK на телевизоре и завершите установку средствами Android.
3. Запустите **Словофон** из списка приложений телевизора.
4. Используйте стрелки пульта для перехода между элементами,
   **OK/Select** для выбора и **Back** для возврата.

Приложение определяет TV по возможностям Android, а не по разрешению экрана.
TV-оболочка использует крупные элементы, выделение фокуса, верхнюю навигацию
и отступы по краям. Для поиска выберите поле ввода и используйте клавиатуру
телевизора. Отдельный голосовой поиск приложения пока не реализован.

TV-адаптация проверена по коду и Flutter-тестам; полноценное подтверждение
на реальных телевизорах и пультах ещё требуется. Для этой проверки подготовлен
[короткий маршрут по экранам и функциям](MANUAL_DEVICE_QA_RU.md).

### Windows

> [!CAUTION]
> **Приложение и установщик Windows пока не подписаны цифровым сертификатом.**
> SmartScreen может показать **«Система Windows защитила ваш компьютер»** и
> **«Неизвестный издатель»**. Для файла из официального GitHub Release сначала
> [проверьте SHA-256](#обновления). Если вы доверяете файлу и хотите его запустить,
> выберите **«Подробнее» → «Выполнить в любом случае»**.
> Отключать SmartScreen или антивирус не нужно. На управляемом ПК политика организации
> может запрещать такой запуск; отсутствие кнопки не следует обходить отключением защиты.

Подробнее о том, как Windows оценивает скачанные приложения:
[Microsoft — репутация приложений в SmartScreen](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation).

1. Скачайте x64 setup из выбранного выпуска и запустите его.
2. Выберите режим установки, каталог и нужные ярлыки. Установка для всех
   пользователей может потребовать права администратора.
3. Откройте **Slovofon** из меню «Пуск» или ярлыка.

Если используете portable ZIP, распакуйте **всю папку**, затем запустите
`Slovofon.exe` внутри неё. Не переносите EXE отдельно от соседних DLL и `data`.
Portable означает запуск без установщика, а не обязательное хранение библиотеки
рядом с EXE.

Основное окно имеет минимальную рабочую область 900×600 логических пикселей.
Навигация находится слева, управление текущей книгой — внизу.
Нижний плеер является частью главного окна: отдельное плавающее mini-player окно
и значок в системном трее пока не реализованы.

## Первая книга

1. Откройте **Поиск**.
2. Введите название книги. При необходимости измените поле поиска:
   автор, чтец, цикл или жанр. Запустите поиск кнопкой поиска.
3. Выберите результат. Проверьте **источник, чтеца и длительность**:
   одинаковое название может встречаться в нескольких озвучках.
4. В карточке книги посмотрите описание и главы. Раздел **«Другие озвучки»**
   помогает перейти к другой доступной версии, если такие версии найдены.
5. Нажмите **Play** для начала прослушивания. Источник отображается своим
   названием и цветом в карточке и плеере.

Словофон работает с Изибук, Akniga, Yakniga, «Книгой в ухе», Книгоблуд и «Базой книг».
Выдача и доступность аудио зависят от самих источников. Наличие результата не
гарантирует полную книгу: обращайте внимание на отметку фрагмента.

## Плеер и библиотека

- **Нижний плеер** позволяет поставить паузу и вернуться к текущей книге,
  не покидая основной раздел. Откройте полный плеер для остальных действий.
- **Перемотка ±15 секунд** меняет позицию; соседние кнопки переключают главы.
- **Скорость**, **таймер сна** и **закладки** доступны в полном плеере.
- **Главная** помогает продолжить последнюю книгу с сохранённой позиции.
- **Библиотека** содержит полки «Слушаю», «Избранное», «Позже», «Скачанные»,
  «Прослушано», закладки и историю. Сердце добавляет книгу в избранное;
  действие «Позже» сохраняет её для следующего прослушивания.

Настройки, история и прогресс сохраняются локально. Аккаунтов и синхронизации
между телефоном, телевизором и ПК сейчас нет: это отдельные библиотеки на каждом
устройстве.

## Офлайн-прослушивание

1. В карточке книги нажмите кнопку загрузки всей книги либо загрузите отдельную главу.
2. Откройте **Загрузки** и дождитесь завершения. Постановка в очередь или частичный
   прогресс ещё не означают готовность аудио для офлайна.
3. Откройте загруженную книгу и выберите скачанную главу. Она может играть без сети;
   для незагруженных глав по-прежнему требуется доступ к источнику.

В «Загрузках» доступны управление очередью, пауза, продолжение, повтор после ошибки
и удаление загруженного аудио. Удаление аудиофайлов не должно удалять избранное,
закладки и прогресс; внимательно читайте подтверждение выбранного действия.
Неполностью скачанный файл не считается готовой главой.

## Настройки

| Раздел | Что можно изменить |
| --- | --- |
| **Внешний вид** | Тему, акцентный цвет, анимации и размер текста 75–200%. |
| **Язык** | Язык интерфейса или выбор языка системы. |
| **Источники** | Выбор источников, участвующих в поиске. Хотя бы один источник должен оставаться включённым. |
| **Кэш карточек** | Посмотреть объём и управлять кэшированными сведениями о книгах. |
| **Обновления** | Вручную проверить наличие новой опубликованной версии. |
| **О приложении** | Посмотреть установленную версию и информацию о проекте. |

**Размер текста** не является общим масштабом операционной системы: он регулирует
текст приложения с учётом системной настройки шрифта. Компоновка подстраивается
под доступное место, а длинные страницы и диалоги прокручиваются.

Выключение источника из поиска не запрещает прослушивание уже выбранной книги
и не удаляет её загрузки. Отдельные разрешения streaming/download поддерживаются
ядром, но их переключатели ещё не выведены в пользовательский экран настроек.

## Обновления

Откройте **Настройки → Обновления**. Словофон проверяет стабильные выпуски напрямую
в [GitHub Releases](https://github.com/Dushnyj/Slovofon/releases),
без промежуточного update-сервера и серверного подписанного манифеста.

Когда подходящее обновление доступно, приложение загружает universal APK на Android
или x64 setup EXE на Windows, **проверяет SHA-256** и только затем передаёт файл
системному установщику. Установка не выполняется скрытно. При отсутствующей или
неверной контрольной сумме файл не должен передаваться на установку.

Если автоматическая проверка не удалась, откройте страницу релизов вручную.
Для ручной загрузки используйте файл и контрольную сумму из одного и того же
выпуска. Пример проверки на Windows — из папки, в которой находится скачанный файл:

```powershell
Get-FileHash -LiteralPath ".\Slovofon-vX.Y.Z-windows-x64-setup.exe" -Algorithm SHA256
```

Замените пример пути на свой файл и сравните хеш с его строкой в `SHA256SUMS.txt`,
если этот файл приложен к выпуску.

## Если что-то пошло не так

| Ситуация | Что проверить |
| --- | --- |
| Поиск пустой | Написание запроса, выбранное поле и включённые источники. Попробуйте другой источник. |
| Книга есть, но аудио не запускается | Сеть и доступность главы; затем действие повтора. Если приложение сообщает о запрете источника, укажите этот текст в обращении. |
| Нет звука офлайн | Завершена ли загрузка именно выбранной главы и не удалены ли её файлы. |
| Загрузка остановилась | Состояние задачи, свободное место и сеть; используйте продолжение или повтор. |
| Android не принимает APK как обновление | Версию и подпись установленной/новой сборки. Не очищайте данные как способ исправления. |
| Пульт не достигает кнопки или текст обрезан | Модель устройства, размер текста, тему и шаги воспроизведения; приложите снимок к обращению. |

Не отправляйте публично полные адреса аудиопотоков, cookies, токены или содержимое
пользовательской базы. Порядок обращения — в [поддержке](../SUPPORT.md), а текущие
ограничения и непроверенные сценарии — в [отчёте качества](CROSS_PLATFORM_QUALITY.md).
