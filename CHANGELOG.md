## [0.0.7] - 2026-09-06

### Added
- Проверка GitHub Releases при возврате в приложение и раз в четыре часа в активном состоянии, с ограничением частоты автоматических запросов. Добавлены регрессионные тесты выбора пакетов, SHA-256, перезапуска, одновременных проверок, native-классификации и диалогов Android/TV/Windows.
- Неустанавливаемый MSI-предпросмотр RU/EN с изолированной идентичностью и блокировкой всех execute sequences. Добавлен read-only валидатор таблиц скомпилированного MSI, подключённый к preview и общей упаковке до подписания/публикации.
- Переоформлен README: шапка с логотипом, навигация, галерея интерфейса и актуальные возможности Android, Android TV и Windows. Добавлены пользовательский быстрый старт, индекс документации, правила участия, поддержка и шаблоны GitHub Issues / Pull Request.

### Changed
- Встроенное обновление Windows сохраняет формат текущей установки: Setup EXE, MSI или portable ZIP. Setup запускается в прежнем режиме и каталоге, MSI — штатным интерактивным мастером; ZIP проверяется и открывается в папке для ручной распаковки без перезаписи работающего приложения.
- Окно обновления показывает описание выпуска и раздельные действия «Обновить», «Позже», «Пропустить версию». Пропуск сохраняется между запусками; ручная проверка в настройках по-прежнему показывает пропущенный выпуск.
- Переработан Setup EXE: системный современный light/dark мастер с фирменной графикой, увеличенным Segoe UI, видимым выбором папки, необязательными ярлыком и запуском. MSI получил локализованный мастер выбора папки и ярлыка, штатные экраны обслуживания и понятные сообщения о сохранении данных.
- EXE/MSI показывают актуальные GitHub-ссылки в сведениях Windows об установленной программе; добавлен общий локальный/CI-скрипт упаковки без перезаписи существующих установщиков.
- В README и инструкции установки Windows добавлен блок Caution об отсутствии цифровой подписи, предупреждении SmartScreen, проверке SHA-256 и подтверждении запуска без отключения защиты системы.
- Версия исходников и приложения синхронно повышена до `0.0.7+7`.
- Добавлена отдельная Android TV-компоновка: определение типа устройства через Android, верхняя навигация пультом, крупные карточки и действия, безопасные поля экрана, контрастный фокус и общий полноценный плеер. Большой телефон/планшет не определяется как TV по ширине.
- На Windows добавлены локальные клавиатурные команды плеера: Space, Ctrl+стрелки (15 секунд), Alt+стрелки (главы), без перехвата ввода в текстовых полях и стандартной активации кнопок.
- Сохранённые книги открываются по реальным metadata, а не через демонстрационную подстановку. Ошибки плеера и запреты источника показываются понятным сообщением; offline file/asset не блокируются запретом streaming.
- Android-карточки получили доступное действие «Позже», сенсорные цели 48 dp и перенос действий/сведений при крупном тексте; выбор полки сохраняется при повороте, диалоги учитывают экранную клавиатуру.
- После визуального ревью уплотнены Windows-результаты поиска: полноширинные строки с приоритетом чтеца и действий, без повторного заголовка запроса. Настройки используют две сбалансированные колонки и постоянное меню перехода к разделам; диалоги получили заголовки и единое поведение выбора.
- В коротком окне карточки книги сначала показывают название и действия, а не большую обложку; загрузки ставят статус, прогресс и управление перед вторичными сведениями. Убраны нулевые счётчики пустых загрузок, добавлен переход к поиску.
- Нижний Windows-плеер при крупном тексте использует компактную компоновку без уменьшения шрифта; полный плеер получил управление громкостью/отключением звука, подписи ±15 на кнопках перемотки и явную прокрутку вкладок.
- Убран дублирующий блок поиска под историей главной. В Windows-настройках оформление, размер текста и параметры карточек редактируются прямо на странице; служебные разделы сгруппированы рядом. Поиск использует полноширинную форму и строки результатов без пустой полосы перед историей/источниками.
- Перекомпонованы Windows-экраны под всю доступную ширину: крупная текущая книга с главами справа, постоянная форма поиска с историей/источниками, широкие строки библиотеки и загрузок, адаптивные группы настроек, двухколоночные карточки книги. Сохранены Android-компоновка, пользовательский масштаб текста и существующие действия; главы остаются ленивыми.
- Диапазон размера текста расширен до 75–200% с шагом 5%, предпросмотром во время перетаскивания и возвратом к 100%; системный масштаб шрифта сохраняется отдельно от настройки приложения.
- Обновлено оформление Windows: sidebar и горячие клавиши разделов, нейтральные light/dark/AMOLED поверхности, типографика, карточки книг, сгруппированные настройки, поиск, библиотека, постоянный playback dock и адаптивный полный плеер. Android сохраняет прежнюю компоновку.
- Windows-карточки учитывают компактный режим, видимость источника и процентов; фокус и hover не меняют геометрию, reduced motion учитывает системную и пользовательскую настройки. Контраст текстового акцента и onPrimary рассчитывается отдельно для desktop.
- Проверка новых версий и скачивание обновлений Android/Windows переведены напрямую на GitHub Releases `Dushnyj/Slovofon`, без промежуточного update-сервера. Контроль SHA-256 обязателен до запуска установщика.
- Из «О приложении» удалены ссылки на сайт проекта, Telegram-бота поддержки и Telegram-канал; ссылка на GitHub, версия и номер сборки сохранены.
- Удалены неиспользуемые проверка серверного Ed25519-манифеста и зависимость `cryptography`; подпись Android APK и конфигурация подписи Windows не менялись.

### Fixed
- Release workflow получает закреплённый Inno Setup 6.7.2 из официального GitHub Release, проверяет SHA-256 до запуска и использует временную portable-копию compiler на runner, не завися от наличия этой версии в Chocolatey.
- Растровые тесты иконок перемотки используют одинаковую тестовую фикстуру Roboto (Apache-2.0) на Windows и Linux, независимо от системных шрифтов и кэша Flutter SDK: отсутствие Segoe UI на GitHub runner больше не подменяет цифры тестовыми блоками и не вызывает ложные ошибки направления стрелок. Фикстура не входит в приложение.
- Проверка стрелок отделяет незначительный краевой антиалиасинг шрифта от тела стрелки; направление дуги, наконечник и немирроренные цифры дополнительно контролируются на уровне векторных команд рисования.
- Тесты установщика канонизируют временную папку Windows перед сравнением путей: короткие имена 8.3 и длинные имена одной папки больше не вызывают ложных ошибок проверки состава MSI и стабильности component GUID в Actions.
- Исправлена автопроверка при запуске: диалог открывается через корневой Navigator, а не из контекста над Router. Повторные ручные и автоматические запросы не создают несколько окон; ошибки загрузки и сохранения пропуска оставляют возможность повторить действие.
- Перед запуском установщика сохраняется актуальная позиция воспроизведения; неподходящий формат и неопределённая регистрация Windows не приводят к запуску другого типа установщика. При неопределённом типе доступна страница релизов.
- Setup блокирует понижение версии и установку поверх MSI/другого scope, MSI — поверх Setup. Повторная установка той же публичной версии не ошибочно сравнивает Flutter build number с нулём; MSI сохраняет прежнюю папку при major upgrade.
- Генератор MSI отклоняет неверные версии, junction/symlink в bundle и output внутри source; пользовательские данные не включаются в очистку установщика.
- Условие запуска приложения на Finish MSI различает отказ от отдельного desktop feature и полное удаление продукта; конечный путь запуска формируется непосредственно перед действием без предупреждения компилятора о Property reference.
- Исправлен контраст бейджа Focus в ThemePreview: используется согласованная пара primary/onPrimary, проверенная в light/dark/AMOLED при 100/200% текста.
- Устранены гонки загрузки/паузы и восстановления плеера: старые decoder snapshots не перезаписывают сохранённую позицию, запоздалое разрешение источника не отменяет Pause; ошибки native engine и Android media session больше не маскируются тестовым проигрывателем.
- Загрузки строго разделяются по источнику и озвучке. Исправлены проверка Range/размера, финализация без потери прежнего файла, сериализация состояния и гидратация очереди, скорость после resume и защита metadata активных/приостановленных задач при очистке кэша. Старые каталоги не переименовываются.
- Разрешения streaming/download проверяются непосредственно перед сетевой операцией, включая повтор и восстановление; отказ не удаляет частично скачанный файл и не блокирует готовые локальные главы.
- Исправлены некорректные списки дорожек Izib, fragment/narrator Akniga, повторная обработка страницы Yakniga и небезопасные автоматические GraphQL redirects; ответы metadata и обложки ограничены по размеру и времени.
- Повреждение необязательных metadata не скрывает все закладки; сохранённые книги доступны после очистки карточного кэша. Экран загрузок больше не выдаёт демонстрационную книгу за отсутствующие metadata.
- Исправлен начальный фокус Windows-оболочки: Ctrl+1…5 работают сразу после запуска и после перехода мышью, не перехватывая навигацию открытого модального диалога.
- Перерисованы Windows-иконки перемотки на 15 секунд в нижнем и полном плеерах: цифры больше не сливаются с дугой и наконечником стрелки, при смене направления отражается только стрелка, а не число. Исправлено соединение дуги с наконечником: назад — против часовой стрелки с направлением влево наверху, вперёд — по часовой с направлением вправо. Действия ±15 секунд и доступные подписи сохранены.
- Процент прослушивания на узкой Windows-обложке больше не разбивается на число и отдельный знак `%`: если выбранный размер текста не помещается, процент целиком переносится к сведениям или прогрессу карточки, без уменьшения шрифта и дублирования.
- Все восемь полок библиотеки подключены к реальным данным вместо пустых заглушек; «Все» объединяет коллекции, избранное, прогресс, загрузки и закладки. Добавлено сохранение «Позже» через меню книги и рабочие закладки с заметкой, точным переходом и подтверждением удаления.
- Метаданные книг с прогрессом и закладками сохраняются отдельно от удаляемого кэша карточек в существующей БД без изменения схемы. Ошибки сохранения не подменяют пользовательские коллекции пустыми данными.
- Частичная ошибка поиска называет недоступные источники и позволяет повторить исходный запрос, сохраняя доступные результаты. Исправлены склонения счётчиков, подписи источников и фаз обновления; одиночный источник нельзя незаметно отключить.
- Исправлены ошибка дерева доступности при открытии меню разделов настроек и уход выбранной вкладки плеера за край после изменения размера окна.
- Основное Windows-окно больше нельзя сжать почти до нуля: минимум 900×600 client DIPs, корректные рамка/DPI и ограничение рабочей областью монитора; проверяются drag/programmatic resize/restore. Узкое окно сохраняет ПК-оболочку с компактной боковой навигацией, адаптивными dock/full player и прокручиваемыми диалогами вместо мобильной нижней навигации.
- При изменении размера окна сохраняются черновики выбора источников/области поиска и прокрутка глав полного плеера. Устранены переполнения окон кэша, отправки ссылки и ошибки загрузки книги, а также некорректный Future-return из обработчика повторной загрузки; меню громкости корректно закрывается по Escape и возвращает фокус кнопке.
- Пустой Windows-плеер предлагает выбрать книгу вместо бесконечного индикатора и неработающих playback-кнопок. Окна скорости и таймера получили явное закрытие; заголовок ошибки поиска больше не остаётся в состоянии загрузки.
- Встроенный ползунок размера текста сохраняет текущий drag и новый предпросмотр при запоздалом сохранении предыдущего значения и адаптивном переносе колонок настроек.
- В «Другие озвучки» Книгоблуд автор больше не попадает в поле чтеца: общий HTML-блок разбирается по ролям. Если чтец не указан, вместо названия книги показывается явная подпись об отсутствии чтеца.
- Источник в плеерах отображается только локализованным названием своим цветом, без префикса «Источник:» и иконки; вкладка информации использует то же правило.
- Светлые оттенки Yakniga и «База книг» немного затемнены в общей палитре источников для читаемого контраста на поверхностях карточек и плееров; цвета карточек и плееров остаются одинаковыми.
- Заголовки AppBar/SliverAppBar больше не ограничивают выбранный размер текста до 134%: высота панели учитывает реальный шрифт. На мобильных карточках источник и процент переносятся в широкую строку при нехватке места под обложкой; общие настройки их видимости и компактности применяются также вне Windows-layout.
- При крупном тексте временные подписи и таймер полного плеера больше не перекрываются; список глав учитывает перенос длительности, а выбор скорости и таймера прокручивается на маленьком экране.
- Мобильные навигация и мини-плеер больше не сбрасывают выбранный размер текста к 100–112%; компоновка подстраивается под шрифт без уменьшения целей нажатия. Закрытие окна оформления во время сохранения не вызывает обновление уничтоженного виджета.
- Исправлено сужение Windows-карточек при увеличении окна: сетка сохраняет читаемую ширину карточек при добавлении колонок, в том числе для одной книги и неполного ряда.
- В Windows playback dock восстановлено отображение источника текущей книги; в большом плеере источник явно подписан и обновляется при смене книги.
- Устранены повторная обработка полного списка глав Yakniga и повторное синхронное сканирование оффлайн-каталога для каждой главы.
- JSON-метаданные сохраняются сериализованно через атомарную замену с резервной копией; повреждённый вспомогательный файл главной больше не блокирует запуск приложения.
- Исправлены очередь Android media-команд, обработка внешней паузы, получение длительности во время загрузки, гонки выбора книги, режим таймера «до конца главы» и Next на последней главе.
- Жизненный цикл Android playback engine отделён от Activity; закрытие интерфейса не убивает процесс плеера безусловно.
- Оффлайн-слой сохраняет исходный сетевой адрес главы; удаление локального файла не закрепляет ссылку на отсутствующий файл. Пауза и отмена прерывают активный поток и освобождают очередь загрузок.
- Добавлены ограниченный срок кэша источников и принудительное обновление временных media URL при восстановлении и повторе ошибочных операций.
- Исправлены закрытие плеера при перетаскивании seek slider, реактивность карточек загрузок и истории главной, ненужное ожидание сети перед Pause и локальным воспроизведением, переполнение metadata chips и desktop viewport в тестах.
- Настройки применяются после hydration без потери других полей; масштаб текста учитывает системную доступность; завершившаяся проверка обновлений закрывает только собственный диалог.
- Поиск обогащает недостающие поля до строгого фильтра; ознакомительные фрагменты сохраняют отдельный статус в источнике, плеере, загрузках и избранном.
- Windows bundle включает redistributable runtime выбранного MSVC toolset; workflow проверяет соответствие release tag собранному commit и не перезаписывает опубликованные артефакты.

### Security
- HTML metadata transport проверяет разрешённые URI до запроса и на каждом redirect; абсолютный адрес из deep link не может обойти metadata allowlist.

## [0.0.6] - 2026-06-17

### Fixed
- Sleep timer больше не «залипает» после истечения: таймер очищался в `Duration.zero`, сохранялся в БД и при следующем запуске приложения мгновенно ставил книгу на паузу через секунду после нажатия Play. Теперь истёкший таймер сбрасывается, а сохранённый `0` из старых сессий игнорируется при восстановлении.

## [0.0.5] - 2026-06-02

### Fixed
- Автопроверка обновлений снова показывает доступную версию при каждом новом запуске приложения: `Пропустить` скрывает обновление только в текущей сессии и больше не сохраняется на диск.
- Android Media3 service больше не останавливает играющую книгу при смахивании приложения из списка последних; если воспроизведение уже остановлено, session и notification очищаются.

## [0.0.4] - 2026-06-02

### Fixed
- Ручная проверка обновлений и скачивание обновления теперь показывают понятное сообщение о проблеме сети с кнопкой `Повторить`, без технических `SocketException`/HTTP-текстов.
- Сетевые ошибки update-flow вынесены в отдельную нормализацию и покрыты тестом, чтобы пользовательские сообщения оставались локализованными и безопасными.

## [0.0.3] - 2026-06-02

### Fixed
- Исправлена внутренняя константа версии приложения: `AppVersion` теперь синхронизирован с `VERSION` и `pubspec.yaml`, поэтому обновление `0.0.2` больше не должно бесконечно определяться как новое после установки следующего патча.
- `tools/slovofon.ps1 version` теперь обновляет `lib/app/app_version.dart`, а release workflow проверяет совпадение версии до сборки.
- Окно обновления показывает простой текст, размер файла, прогресс скачивания и скорость без технического описания проверки подписи/sha256.
- Android updater проверяет разрешение на установку APK до скачивания и открывает системные экраны без отдельного task, чтобы возврат из настроек не сбрасывал пользовательский контекст.
